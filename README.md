# 한국형 전기 시내버스 | 스마트팩토리 3D 디지털 트윈

- **원본 파일**: `ThreeJS_한국_시내버스_조립공장_3D.html`
- **엔진**: Three.js r180 (ES Modules)
- **목적**: 한국형 저상 전기 시내버스의 조립 공정을 8단계로 시각화한 교육용 가상 스마트팩토리 시뮬레이터 (실제 제조사의 공정 순서나 부품 치수를 복제하지 않은 개념 모델)

---

## 1. 3D 가상 조립공장 환경 (`BAY 01`)

- **공장 건축물**: 천장 H빔 트러스 구조, 채광창, 배기 덕트, 바닥 안전 구획선 및 컨베이어 롤러 라인
- **자동화 설비**:
  - 상부 천장 크레인 레일 및 리프팅 후크
  - 조립 라인 양측에 배치된 산업용 다관절 로봇 암 2기 (조립 상태에 따라 동작)
  - 부품 팔레트, 작업대 및 안전 표지판

---

## 2. 버스 조립 8단계 공정

| 단계 | 공정명 | 주요 조립 부품 (`partId`) | 공정 설명 |
| :---: | :--- | :--- | :--- |
| **01** | **섀시 프레임** | `chassis` | 강재 종방향 프레임과 횡방향 보강대로 차량의 하부 기초 플랫폼 구성 |
| **02** | **차축·바퀴** | `wheels` | 전후 차축(액슬), 서스펜션 스프링, 휠 및 타이어 4본 장착 |
| **03** | **배터리·전기 구동계** | `battery` | 하부 고전압 배터리 팩 3기, 전력변환기, 전기 구동 모터 및 고전압 케이블 배치 |
| **04** | **차체 골격** | `skeleton` | 측면 수직 필러(기둥), 상부 횡보 및 지붕 프레임 결합 |
| **05** | **외판·지붕 도장** | `shell-near`, `shell-far`, `front`, `rear`, `roof` | 도장된 측면 외장 패널, 전·후면 범퍼, LED 전광판 및 지붕 상부 공조 하우징 부착 |
| **06** | **창문·출입문** | `glass`, `doors`, `lights` | 전면 파노라마 유리, 측면 안전유리, 이중 미닫이 승하차 출입문, 사이드미러 및 조명 장착 |
| **07** | **실내·편의시설** | `interior` | 저상 통로 바닥, 승객 좌석, 노란색 안전 손잡이, 운전석 및 대시보드 설치 |
| **08** | **완성·품질 검사** | `qa` | 전장·조명·도어 작동 점검 및 가상 레이저 스캐너를 통한 최종 품질 검사(`PASS`) 연출 |

## 3. 인터랙티브 기능 및 관제 UI

### 공정 제어 및 시각화 옵션
- **자동 조립 시퀀스**: `▶ 자동 실행` 버튼 또는 `Space` 키로 1단계부터 8단계까지 순차 조립 애니메이션 재생 (재생 속도 `0.75×` ~ `2×` 조절 가능)
- **차체 도장 색상 변경**: 한국 시내버스 대표 노선 색상 4종 지원
  - **간선 (`blue`)**: `#006dc5` (기본값)
  - **지선 (`green`)**: `#228c6c`
  - **광역 (`red`)**: `#ba3a4e`
  - **순환 (`yellow`)**: `#dba831`
- **특수 관찰 모드**:
  - **도어 열기**: 6단계(창문·출입문) 이상에서 승하차용 이중 미닫이문 개폐 작동
  - **분해 보기 (`Explode`)**: 각 조립 모듈을 공간적으로 펼쳐 내부 결합 구조 확인
  - **X-RAY 모드**: 차체 외판과 유리를 반투명하게 전환하여 내부 골격 및 좌석 투시
  - **360° 자동 회전**: 카메라 자동 공전 토글

### 카메라 시점 프리셋
- **사선 전경 (`overview`)**: 조립 라인과 버스 전체를 입체적으로 조망하는 기본 뷰
- **측면 (`side`) / 전면 (`front`) / 후면 (`rear`)**: 각 방향의 외관 및 장비 확인 뷰
- **실내 (`cabin`)**: 버스 내부 객실 및 운전석 관찰 뷰 (선택 시 자동으로 7단계 이상 및 X-RAY 활성화)
- **상부 (`top`) / 하부 (`under`)**: 지붕 전장 모듈 및 하부 섀시·배터리 배치 확인 뷰

### 디지털 트윈 관제 패널 (우측 사이드바)
- **KPI 모니터링**: 공정 진행률(`%`), 완료 공정 수(`01 / 08`), 작업 상태, 가상 품질 상태 표시
- **부품 인스펙터**: 3D 화면에서 조립된 부품을 직접 클릭하면 해당 모듈의 명칭, 구조 설명 및 설치 단계 표시
- **공정 이벤트 로그**: 단계 변경, 도색 변경, 도어 작동 등 사용자 조작 이력을 실시간 시간순으로 기록
- **화면 저장**: 현재 3D 조립 화면을 `PNG` 이미지 파일로 다운로드
